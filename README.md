# Space Survival Game

![Game Screenshot](screenshot.png) <!-- Замените на реальный скриншот игры -->

Простая космическая игра, написанная на Python с использованием библиотеки Pygame. Управляйте космическим кораблём, избегайте падающих метеоритов и старайтесь продержаться как можно дольше!

## Особенности
- 🚀 Управление космическим кораблём с помощью клавиатуры (стрелки)
- ☄️ Случайное появление метеоритов
- 🌟 Звёздный фон для атмосферности
- 🔊 Звуковые эффекты столкновений и завершения игры
- 📊 Счётчик попаданий (после 5 столкновений — Game Over)

## Установка и запуск
1. Убедитесь, что у вас установлен Python (рекомендуется версия 3.8+)
2. Установите библиотеку Pygame:
   pip install pygame
3. Скачайте файлы игры (main.py, spaceship.png, meteor.png, hit.wav, game_over_sound.wav) в одну папку.
4. Запустите игру:
  python main.py
